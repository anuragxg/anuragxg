**A smarter way to track the job hunt.**

A full-stack application designed to manage job applications, company details, roles, and application statuses in one place.

| Module | Technology |
|:--|:--|
| Frontend | React + Vite |
| Backend | Node.js + Express |
| Database | MongoDB + Mongoose |
| Authentication | JWT |
| API | REST |
| Deployment | Vercel |

**Core features**

- 📋 Track companies, job roles, and application dates.
- 🔄 Manage job application statuses.
- 🔐 Authenticate users with JWT.
- 🍃 Persist application data with MongoDB.
- 🌐 Access the deployed application online.
